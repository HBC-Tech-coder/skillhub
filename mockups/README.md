# SkillHub（技能港）UI 风格参考页

三个文件都是**自包含单页 HTML**（无外部依赖、无网络请求），双击即可在浏览器打开。三者共用同一份 8 条示例数据（4×DSH + WorkBuddy + TRAE + MCP，全部为示意数据），交互一致：搜索、生态筛选、分类筛选、卡片详情弹窗、复制安装命令。

| 文件 | 风格 | 适合 |
|---|---|---|
| `style-a-clean.html` | 亮色极简（Product Hunt / Linear 风） | 国际化、开发者工具感、留白多 |
| `style-b-dark.html` | 暗色开发者风（GitHub Dark 风） | 程序员受众、终端感、和 dsh-market 气质接近 |
| `style-c-vivid.html` | 中文门户 / 应用商店风（渐变 hero + 分类瓷砖 + 热门榜） | 中文用户、市场感强、可挂备案号 |

## 选择后

选定风格（或说出想混合的元素，如「A 的布局 + C 的 hero」）后，我会以它为基准实现正式站点：接真实 `plugins.json`、详情页/分类页、多语言、giscus 评论占位等。

## 注意

- 页面里所有条目、星标、安装命令均为示例（部分真实存在的插件名字仅作数据形状演示）。
- 最终站点会从 `plugins.json` 拉取数据，卡片字段按 dshmarket 兼容 schema 设计。
